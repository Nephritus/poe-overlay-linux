# 11: UI scale and opacity

**What to build:** General has one UI scale (for example 75%–150%) and one background opacity for all Panels, in the Menu and the Settings window. Changes apply live to every Panel, including the Menu itself, and text stays crisp.

**Blocked by:** 04 (The Menu)

**Status:** ready-for-agent

- [ ] Changing the scale resizes every Panel at once, with no restart
- [ ] Changing the opacity changes every Panel's background, not its text
- [ ] Panels stay wholly on screen after a change of scale
